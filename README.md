Чето типа небольшой операционной системы, ОС делается под загрузку с флоппи дисков, проверяется на виртуальной машине qemu-system-i386, есть в репозиторях pacman.

Сейчас находится в финальной версии 1.0, в силу монолитности проекта, его становится очень тяжело отлаживать.
Реализовано:
1. Загрузка с HDD-USB дисков заместо флоппи
2. Некоторые команды: larp, mem, help, echo
3. Своя файловая система (MyFS)
