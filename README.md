Чето типа небольшой операционной системы, ОС делается под загрузку с флоппи дисков, проверяется на виртуальной машине qemu-system-i386, есть в репозиторях pacman.


Пишу на языке ASSEMBLER (NASM), в целях добавить компилятор для C, перечень встроенных утилит: создание/удаление файлов, запись данных в файлы, проигрывание МП3 и м4а файлов.

В ближайшее время добавлю полноценную файловую систему FAT12, рассчитываю на поддержку файлов созданных в Linux.
